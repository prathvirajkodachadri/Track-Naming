# Indian Song Track Naming Standard

A public, browser-based reference for professional Cubase track naming in Indian music projects.

## Features
- Search and filter 243 track-name examples by family, role, or plugin.
- Edit instrument and plugin fields to generate a track name.
- Copy generated names with one click.
- Category color coding and arrangement order matching the reference HTML.
- Static site: no build tool, backend, or sign-in needed for visitors.

## Publish
This site is deployed via GitHub Pages. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source. The `pages.yml` workflow deploys `index.html` from `main`.
